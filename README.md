# Algorithmic Phronesis vs. Human Expertise

[![Repository](https://img.shields.io/badge/GitHub-arad1367%2FAlgorithmic__Phronesis-blue?logo=github)](https://github.com/arad1367/Algorithmic_Phronesis)

This repository contains the replication code and qualitative data for the manuscript **"Algorithmic Phronesis vs. Human Expertise: A Retrospective Sociomaterial Case Study of Autonomous AI Agents in a Specialized IT Firm."** 

Please note that this repository is intended strictly for peer-review and methodological transparency. To preserve the integrity of the ongoing double-blind review process, no statistical results, outputs, or figures are displayed in this repository.

## 📂 Repository Structure

```text
Algorithmic_Phronesis/
├── data/
│   └── Interviews.json       # Anonymized transcripts of the 18 critical incident interviews
├── analyze_logs.py           # Python script for quantitative OLS regression and t-tests
├── analyze_interviews.py     # Python script for qualitative thematic analysis
└── README.md                 # Project documentation
```

## 📥 Getting Started

To clone this repository and run the analysis scripts locally, use the following commands:

```bash
git clone https://github.com/arad1367/Algorithmic_Phronesis.git
cd Algorithmic_Phronesis
```

## 📊 Data Availability Statement

**Qualitative Data:** 
The fully anonymized transcripts from the 18 critical incident interviews are provided in JSON format (`data/Interviews.json`) and can be used directly with the qualitative analysis script.

**Quantitative Data (Confidential):**
The quantitative dataset consists of 1,528 digital trace logs and Experience Sampling Method (ESM) scores generated by a specialized IT firm. Due to Non-Disclosure Agreements (NDA) and strict privacy protocols regarding proprietary algorithmic interactions, the raw system logs (`logs.csv`) cannot be shared publicly in this repository. 

*Note for Reviewers/Editors:* A fully anonymized version of the quantitative dataset is available strictly for the purpose of peer review. Please contact the corresponding author to request secure, confidential access to the data.

## ⚙️ Code Execution and Usage

### 1. Quantitative Analysis (`analyze_logs.py`)
This script performs descriptive statistics, Levene's test for equality of variances, independent samples t-tests (with Cohen's *d* effect size), and the HC3 robust Ordinary Least Squares (OLS) regression.
* **Usage:** Place the requested `logs.csv` file in the root directory and execute the script.
```bash
python analyze_logs.py
```

### 2. Qualitative Analysis (`analyze_interviews.py`)
This script processes the qualitative interview data, extracting first-order concepts and second-order themes according to the Gioia methodology outlined in the manuscript.
* **Usage:** The script will automatically read from `data/Interviews.json`.
```bash
python analyze_interviews.py
```
